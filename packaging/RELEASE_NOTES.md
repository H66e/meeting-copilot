## Meeting Copilot v0.2.1 · Windows 预览版

面向研究组会与经允许的面试练习的 Windows 桌面实时助手。

### 下载

- `MeetingCopilot-v0.2.1-Windows-x64.zip`：免安装文件夹版，完整解压后运行 `MeetingCopilot.exe`。
- `MeetingCopilot-v0.2.1-Windows-x64.zip.sha256`：发布包 SHA256 校验文件。

不需要单独安装 Python。请保持 exe 与 `_internal` 文件夹在一起，不要直接在 ZIP 内运行。

### 本版修复

- 修复开始或恢复聆听后立即讲话时，最初 0.5 秒热身可能把第一句话当作噪声、导致整句不显示的问题。
- 热身期间保留有界音频缓存；检测到持续讲话时恢复完整句首，同时保留原有静音、噪声自适应和长句切分行为。
- 新增冷启动回归测试，并完成可控中文合成语音、真实录音固定样本测速及自由提问真实链路验收。

### 已有功能

- Apple 式浅色工作台：统一工具条、可调整双栏、连续自由提问、历史回顾与画面定格。
- 组会／面试双场景、实时字幕、应答思路、自然照读稿与本地纪要。
- 设置页分组、窗口缩放、输出设备与识别模型选择。
- faster-whisper 本地识别，模型缓存优先，无缓存时可联网下载。
- OCR、公共配置模板、应用图标和中文使用说明。

### 运行前请知悉

- Windows 10／11 x64；Whisper 模型不随 ZIP 分发，首次准备模型需要网络。
- 云端回答需要自行配置 OpenAI 兼容 API；请阅读包内 `使用说明.txt`。
- 默认不保存整场原始音频。使用云端 LLM 或视觉模型时，相关文本或截图会发送给对应提供商。
- 本版未配置商业代码签名，Windows 可能提示未知发布者。请核对来源和 SHA256。
- 这是实验性预览版，尚未完成人工逐字稿、多种噪声和不同设备的完整真实会议验收；持续背景声仍可能干扰能量 VAD，不保证识别与回答准确。

仅用于获得参与者同意、符合机构规定及面试规则的场景。许可证：Apache-2.0。
